Модуль `src/confdb/bsl_syntax.py` — проверка синтаксиса языка 1С (BSL). Это
собственная реализация на чистом Python (лексер и рекурсивный парсер), написанная
с нуля, а не перенос кода из Java-проекта BSL Language Server. В качестве
чек-листа грамматики языка использованы открытые ANTLR-грамматики
`BSLParser.g4` и `BSLLexer.g4` проекта **bsl-parser**
(https://github.com/1c-syntax/bsl-parser, лицензия LGPL-3.0-or-later,
Copyright (c) 2018-2026 Alexey Sosnoviy, Nikita Fedkin, Sergey Batanov и др.).
Из этого проекта не копировался ни исходный код, ни сгенерированный парсер —
воспроизведены только правила грамматики (структура языка), которые сами по себе
описывают публичный синтаксис BSL. Имена диагностик (`ParseError`,
`InvalidCharacterInFile` и т.п.) совпадают с именами BSL Language Server для
совместимости выдачи.
